## Sobre o projeto

A ideia foi criar um card visual de apresentação de estatísticas, parecido com aqueles componentes usados em páginas de empresas, dashboards ou sites institucionais.

O layout mostra um texto principal, uma breve descrição, alguns números de destaque e uma imagem com uma camada de cor por cima para combinar com o estilo da página.

## Como comecei

Primeiro, montei a estrutura básica do HTML, colocando o título, a descrição e os três blocos de estatísticas dentro de um card principal.

Depois, adicionei a imagem lateral e organizei os elementos para que o conteúdo ficasse dividido em duas partes: texto de um lado e imagem do outro.

## Estilização

No CSS, trabalhei as cores, fontes, espaçamentos e alinhamentos para deixar o layout mais parecido com uma página profissional.

Usei uma cor escura no fundo, um card com tom roxo escuro e destaque em roxo mais claro na palavra “insights”. Também utilizei fontes externas para deixar o visual mais agradável.

## Responsividade

Depois de montar a versão para computador, ajustei o layout para telas menores.

No celular, o card passa a ficar em coluna, com a imagem em cima e o texto embaixo. Isso ajuda o conteúdo a não ficar apertado e melhora a leitura em telas pequenas.

## Organização do código

Também organizei melhor o HTML e o CSS, removendo algumas repetições e corrigindo pequenos detalhes que poderiam atrapalhar o redimensionamento da página.

Um dos cuidados foi evitar alturas fixas que poderiam cortar o conteúdo em algumas telas. Assim, o layout fica mais flexível e se adapta melhor.

## Resultado final

O resultado final é um componente simples, organizado e responsivo, mantendo o foco no visual e na experiência do usuário. O projeto me ajudou a praticar estruturação com HTML, estilização com CSS, uso de fontes, imagens, cores e adaptação para diferentes tamanhos de tela.
